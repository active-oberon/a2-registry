LocalSockets.Connection.WriteLine

A line ended with one newline, and sent at once. That is what a control socket wants: one line is one command, and it is no use sitting in a buffer. Streams.Writer.Ln would put a carriage return in front of it.

LocalSockets.Connect

Talk to whatever is listening at that path. NIL when there is nothing there, which is what a program that is not running looks like from here.

Syntax

LocalSockets.Listen

Listen at that path, so that others can connect to it. The name must be free: a socket left behind by something that died is removed first, which is what every program that does this ends up doing. NIL when it cannot be had.

Syntax
