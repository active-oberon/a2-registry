FoxA64Assembler.Assembler.GetImmediateValue

an immediate: '#' and then a constant expression

The one floating point immediate A64 has is the zero of `fcmp d0,

0.0`, and it is read here rather than through the shared expression parser, which builds an integer out of every number it is given. Nothing else in the instruction set takes a floating point constant the others are loaded from memory.

Syntax

PROCEDURE GetImmediateValue* (VAR value: Basic.Integer): BOOLEAN

FoxA64Assembler.Test

assemble the text that follows the command and write the words it produced, one per line

Nothing in the compiler drives the parser without a code generator behind it, so this is how it is exercised: the same instructions the encoder's own self test prints are read back through the parser here, and the words have to come out the same. That checks the parser against the encoder, and -- since the encoder's output is checked against llvm-mc -- the parser against llvm-mc as well.

The section and module the parser writes into are the smallest ones that satisfy it: it needs somewhere to put bits and somewhere to look a symbol up, and neither has to belong to a real compilation.

PROCEDURE Test* (context: Commands.Context)
