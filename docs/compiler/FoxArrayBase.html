FoxArrayBase.ExpandDimensions

create an array with the same data but with more dimensions each element in the array 'keptDimensions' corresponds to a dimension in the resulting array if element = TRUE: use a dimension from the source array, i.e. reuse length and increment if element = FALSE: insert a new dimension having length = 1 and increment = 0

e.g.
ExpandDimensions(array, FALSE, TRUE, FALSE, FALSE, TRUE]) performs the following type transformation: ARRAY 10, 20] OF FLOAT32 -> ARRAY 1, 10, 1, 1, 20] OF FLOAT32

Syntax

PROCEDURE ExpandDimensions* (CONST sourceArray: ARRAY [?]; CONST keptDimensions: ARRAY [*] OF BOOLEAN): ARRAY [?]
