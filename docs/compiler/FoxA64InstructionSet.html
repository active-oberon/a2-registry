FoxA64InstructionSet.Operand

one operand of an A64 instruction

The record covers every operand shape the instruction set has, and each encoder reads only the fields its form uses. A memory operand is the one that uses most of them: `register` is the base, `index` the offset register when there is one, `shiftMode`/`extend`/`shiftAmount` the way that offset register is widened and scaled, and `immediate` the offset when there is not.

FoxA64InstructionSet.Encode

encode one instruction into the 32 bit word the processor reads

FALSE means the mnemonic and the operands do not name an instruction that exists -- an immediate out of range, a register of the wrong width, an addressing mode the form does not have. It is never a silent approximation.

Syntax

PROCEDURE Encode* (CONST instruction: Instruction; VAR code: SIGNED32): BOOLEAN
