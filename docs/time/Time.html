AUTHOR "Andrii Puhachenko"; PURPOSE "Two clocks the library did not have: one that never goes backwards, and one that says UTC"; LIMITATIONS "- no time zone database: Zone reports the offset the host is running in, which is what Clock reads from the system for this instant, and that is all -- naming a zone or asking what a past date's offset was needs the IANA database and is not here; - leap seconds are POSIX's, i.e. ignored: a Unix time is 86400 seconds a day."
