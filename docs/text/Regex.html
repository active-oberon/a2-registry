AUTHOR "Andrii Puhachenko"; PURPOSE "Regular expressions for Active Oberon, matched without backtracking"; LIMITATIONS "- UTF-8 in, byte offsets out: Find and Group report where a match is in bytes, because that is what a caller indexes with; a byte that is not well-formed UTF-8 is matched as the character of that byte's value, so a broken string cannot stall the search; - simple case only: there is no case-insensitive flag yet; - no back references (a back reference is what makes matching exponential, and this engine trades it away on purpose); - {m,n} is written out into the program, so a count is capped at MaxRepeat; - ^ and $ anchor the whole text, not a line; - at most MaxGroups capturing groups; - a compiled Regexp carries the result of its last search, so it is a searcher and not a shared constant: give each activity its own; - Split ignores an empty match, because splitting on one produces one piece per character and nobody means that."
