Module PKCS1

Implementation of the PKCS#1 encryption scheme for RSA. See RFC 2437. Timothée Martiel, 2014

Summary

procedures Encrypt (CONST src: ARRAY OF CHAR; srcOfs, srcLen: SIZE; key: CryptoRSA.Key; blockType: SIGNED32; VAR dest: ARRAY OF CHAR; destOfs: SIZE; VAR destLen: SIZE)

PKCS1.Encrypt

Encrypts src[srcOfs] .. src[srcOfs + srcLen - 1] with key and writes the result starting from dest[destOfs]. destLen returns the total written length. It uses a block type as specified by blockType. blockType can be 0, 1 or 2. destLen = 0 iff encryption failed.

Syntax

PROCEDURE Encrypt* (CONST src: ARRAY OF CHAR; srcOfs, srcLen: SIZE; key: CryptoRSA.Key; blockType: SIGNED32; VAR dest: ARRAY OF CHAR; destOfs: SIZE; VAR destLen: SIZE)

PKCS1.Decrypt

Decrypt src[srcOfs] .. src[srcOfs + srcLen - 1] with key, checking for a PKCS#1 formatting with block type blockType. The result is written in dest[destOfs] .. dest[destOfs + destLen - 1]. destLen is written with the data length. destLen = 0 iff decryption failed or PKCS badly formatted.

Syntax

PROCEDURE Decrypt* (CONST src: ARRAY OF CHAR; srcOfs, srcLen: SIZE; key: CryptoRSA.Key; blockType: SIGNED32; VAR dest: ARRAY OF CHAR; destOfs: SIZE; VAR destLen: SIZE)
