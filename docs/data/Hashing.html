AUTHOR "Andrii Puhachenko"; PURPOSE "Hash and equality for the key types a Map is usually keyed by"; LIMITATIONS "- not a cryptographic hash and not resistant to a chosen-key attack: this is a good spread and nothing more. A map fed keys from a hostile network wants a keyed hash; - strings hash by bytes, so two spellings of the same text in different normal forms are different keys; - the constants are FNV-1a's but the basis is not, so these numbers are this library's and not comparable with another implementation's."
