CSV.Scanner

Responsible for scanning a Stream and interpreting it in CSV format

Configuration is passed via the File: Field separator character Quoting Characters Escape Character

Scan
The function for scanning the whole file. Scans the content of the stream into the file passed to Init. ScanLine or ScanField just scan a line or a field.
