CalcGrunwald.MaxIntervals

Arguments of differ-integration are: f the function being differintegrated, x the argument of f, also the upper limit of differintegration, order (> 0) the fractional order of differintegration, i.e., a, error the requested and achieved error tolerances, res status of the differintegration.

CalcGrunwald.SolveD

Computes a Riemann-Liouville fractional-order derivative. Daf(x) = DnIaf(x) = (1/G(n-a)) dn/dxn x0x (x-y)n-1-a f(y) dy, n-1 # n, n N

, a N !+

Syntax

PROCEDURE SolveD* (f: CalcFn.ReArg; x, order: NbrRe.Real; VAR error: NbrRe.Real; VAR res: NbrInt.Integer): NbrRe.Real

, a N !+

CalcGrunwald.SolveI

Computes a Riemann-Liouville fractional-order integral. Iaf(x) = (1/G(a)) x0x (x-y)a-1 f(y) dy, a N !+
