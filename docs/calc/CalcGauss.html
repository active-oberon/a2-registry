Gauss-Kronrod integrators that solve to a specified error tolerance achieved by automatic subdivision.

CalcGauss.Coarse

Admissible parameters to pass that select the 'integrator'. Coarse should only be selected for smooth integrands. Medium should be used as the default. Fine should be selected for oscillating integrands.

Syntax

CONST Coarse*= 99

CalcGauss.OKay

Status of an integration, i.e., the admissible values for the returned parameter 'res'.

Syntax

CONST OKay*= 0

CalcGauss.MaxIntervals

Upper bound on the number of subintervals of integration.

Syntax

VAR MaxIntervals-: NbrInt.Integer

CalcGauss.Solve

Computes I(f) = xab f(x) dx to a specified error tolerance.

Syntax

PROCEDURE Solve* (f: CalcFn.ReArg; a, b: NbrRe.Real; integrator: NbrInt.Integer; VAR error: NbrRe.Real; VAR res: NbrInt.Integer): NbrRe.Real
