MatrixBlockSolvers.LU

see http://www.maths.man.ac.uk/~nareport/narep207.pdf/demmel95block.pdf

A=LU; diagonal blocks are squareA= A11,A12],[A21,A22=[[I,0],[L21,I * A11,A12][0,S i.e.

A = A11,A12] = I , 0] * A11,A12] A21,A22] L21,I] 0 , S

S = Schur Complement = A22-A21 * A11inv * A12to be applied recursively

specifically
1) U11:=A11; U12 := A122) Solve L21*A11 = A21 for L21 either using Gauss Elimination with partial pivoting or or compute A11inv explicitely, so that step 2 becomes a matrix multiplication and Ux=y is solved entirely by matrix vector multziplication3) S := A22 - L21 * A12 (Schur complement)4) Compute LU factorisation of S recursively

given the block factorisation of A, the solution to a system Ax=b can be obtained by solving Lx=y by forwardsubstitution since L is triangular, and solving Ux=y by block back substitution.
