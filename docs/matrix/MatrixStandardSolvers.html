MatrixStandardSolvers.GaussJordan

Decompose +/- Solve a linear system by the Gauss-Jordan algorithm , with full pivoting; using only the NEW(solver,A) or solver.Init(A) part, matrix inversion is performed; slower than Gauss, but suited for direct computation of the matrix inverse
