Traps.Handler

What a debugger in this process is told when a trap is about to end an activity.

Syntax

TYPE Handler* =PROCEDURE{DELEGATE} (sig, trapno: SIGNED32; pc, bp, sp, stackHigh: ADDRESS)

Traps.Resumer

What a debugger is asked when a trap could be a breakpoint it planted. TRUE means it was one the activity resumes at `pc`, which the debugger may have moved, and nothing of the trap is printed. FALSE means the trap is the program's own.

Syntax

TYPE Resumer* =PROCEDURE{DELEGATE} (VAR pc: ADDRESS; bp, sp, stackHigh: ADDRESS): BOOLEAN
