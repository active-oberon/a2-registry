Loader.Arrangement.Patch

write `bits` bits of `value` at bit `offset` of the byte at `pos`

The whole byte case is what the backends of the Intel machines produce and it stays a byte at a time. A fixup that does not fill its bytes -- the displacement of a branch on a machine with fixed width instructions sits inside the instruction word -- has to keep the bits around it, so that one goes bit by bit, the way `BitSets.SetBits` does it for the linker. It used to be an assertion instead, which made every such fixup a trap.
