JSON.ReadFrame

ReadFrame reads one framed message. `alive` says whether the stream is still usable: it is FALSE only for end of input or a header we cannot make sense of, and TRUE with a NIL result for a message whose body is not JSON -- the frame gave its length, so exactly that many bytes were consumed and the next message is still where it should be. One bad message from an editor is not a reason to drop the session.

Syntax

PROCEDURE ReadFrame* (in: Streams.Reader; VAR alive: BOOLEAN): Value
