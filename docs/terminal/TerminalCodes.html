TerminalCodes.Event

One thing that happened at the terminal. `kind` says which of the other fields mean anything Character uses `char`, Key uses `key`, Mouse uses `button` and `x`, `y` -- which count from one, as the terminal reports them. `modifiers` holds Shift, Alt and Ctrl.

TerminalCodes.Read

The next event, read from whatever the terminal (or a test) is sending. FALSE when there is nothing more to read.

A lone escape is the Escape key, and an escape with more behind it starts a sequence: the difference is whether anything follows, which is why this asks the reader what it has. A terminal sends a sequence in one burst, so a caller reading a real one should let the bytes arrive before deciding -- Terminal.Read does that waiting.

Syntax

PROCEDURE Read* (r: Streams.Reader; VAR e: Event): BOOLEAN
