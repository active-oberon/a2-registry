Terminal.Open

Hand over every key as it is pressed, and stop echoing. FALSE if standard input is not a terminal, which is the honest answer for a program with its input redirected.

Terminal.Resized

Has the window changed size since this was last asked? A program asks once around its event loop and redraws when the answer is yes.

Syntax

PROCEDURE Resized* (): BOOLEAN

Terminal.Read

The next thing that happened at the terminal, waiting for it. FALSE when standard input has ended, which is how a program is told to stop.

An escape sequence arrives in one burst but is several bytes, and the escape key is one byte that looks like the start of one. So after an escape this waits a moment for the rest to turn up, and calls it the escape key only when nothing does.

Syntax

PROCEDURE Read* (VAR e: Event): BOOLEAN

Terminal.Pending

Has something been typed? A program with more than the keyboard to watch -- a child's output, a socket -- asks this instead of reading, and gets on with the rest when the answer is no.

Syntax

PROCEDURE Pending* (): BOOLEAN
