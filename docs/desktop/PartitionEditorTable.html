PartitionEditorTable.LoadPartitionTable

This procedure is called by the Partition Editor when you press the Load button. It should load the block number <block> on the device <devicename> and extract the partition table inside if any

Syntax

PROCEDURE LoadPartitionTable* (CONST devicename: ARRAY OF CHAR; block: SIGNED32; VAR res: INTEGER): PartitionTable

PartitionEditorTable.StorePartitionTable

This procedure is called by the Partition Editor when you press the Store button. It shall encode the given partition table <pt> into a 512 bytes block and store this block on the named device at block number <block>

Syntax

PROCEDURE StorePartitionTable* (CONST devicename: ARRAY OF CHAR; block: SIGNED32; CONST pt: PartitionTable; VAR res: INTEGER)

PartitionEditorTable.Changed

This procedure is called by the Partition Editor when the user presses the enter key on an editor component. Dependent of the changeType, we should now fixup all other entries of the provide partition table entry, e.g. if the start LBA changed, we should adjust the start CHS and the partition size. The Partition Editor will visualize changes we do to the Partition record

Syntax

PROCEDURE Changed* (changeType: SIGNED32; VAR partition: Partition; CONST devicename: ARRAY OF CHAR; VAR res: INTEGER)

PartitionEditorTable.Clear

Set all entries the partition table <partitionTable> to zero, needed by editor component. Can also be used here.

Syntax

PROCEDURE Clear* (VAR partitionTable: PartitionTable)
