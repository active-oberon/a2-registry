WMColorPicker.PickColorXY

Open a ColorPickDialog at x:y position with default value color. Return ResOk or ResAbort. If res is ResOk color contains the selected color. Color is not changed if res is ResAbort

Syntax

PROCEDURE PickColorXY* (x, y: SIZE; VAR color: WMGraphics.Color): WMGraphics.Color
