X.509 Certificates and certificate management. See RFC5280 standard. Written by Timothée Martiel, 2014, with some fragments by P. Hunziker.

X509.AllowNotTrusted

Verification flags

Allow valid certificates that are not linked to the trusted root certificates

Syntax

CONST AllowNotTrusted*= 0

X509.AllowOutdated

Allow certificates that are not valid anymore

Syntax

CONST AllowOutdated*= 1

X509.Bypass

Bypass all checks

Syntax

CONST Bypass*= 31

X509.Entity

Represent an issuer or a subject. Only mandatory fields are kept. Fields are NIL if not present.

Syntax

TYPE Entity* =RECORD

Summary

variablescountry: POINTER TO ARRAY OF CHAR
organisation: POINTER TO ARRAY OF CHAR

distName: POINTER TO ARRAY OF CHAR
state: POINTER TO ARRAY OF CHAR
commonName: POINTER TO ARRAY OF CHAR
serial: SIGNED32

X509.Certificate

Base certificate type. Certificates are specialized according to the encryption algorithm they provide.

Syntax

TYPE Certificate* =POINTER TO RECORD

Summary

variablesversion: SIGNED32
serial: SIGNED32
algorithm: POINTER TO ARRAY OF CHAR
validity: RECORD
identifier: POINTER TO ARRAY OF CHAR
publicKey: CryptoRSA.Key
issuer: Entity
subject: Entity
parent: Certificate
