Locks.RWLock

Implements a Reader/Writer lock that can be taken by many readers at the same time, as long as no writer lock was taken. Only one writer lock is possible at one time. (MREW = Multi Read, Exclusive Write) Writers can starve. Possible remedies : simple : Don't let new readers in if a writer made an acquire. more complicated: Q all acquires and handle in order (optimizing readers) Readers trying to get a Writer lock result in a trap. Currently no upgrade.
