Streams.Writer.Date

Write the date and time in ISO format (yyyy-mm-dd hh:mm:ss). The t and d parameters are in Oberon time and date format. If all parameters are within range, the output string is exactly 19 characters wide. The t or d parameter can be -1, in which case the time or date respectively are left out.

Syntax

PROCEDURE Date* (t, d: SIGNED32)

Streams.Writer.Date822

Write the date and time in RFC 822/1123 format without the optional day of the week (dd mmm yyyy hh:mm:ss SZZZZ) . The t and d parameters are in Oberon time and date format. The tz parameter specifies the time zone offset in minutes (from -720 to 720 in steps of 30). If all parameters are within range, the output string is exactly 26 characters wide. The t, d or tz parameter can be -1, in which case the time, date or timezone respectively are left out.

Syntax

PROCEDURE Date822* (t, d, tz: SIGNED32)

Decodes a UTF-8 encoded character from a byte stream into a 32-bit Unicode code point. Returns TRUE if a valid UTF-8 sequence is decoded and ucs is set, FALSE for invalid sequences (U+D800–U+DFFF, >U+10FFFF) or insufficient bytes.

On success, advances the stream position by the appropriate number of bytes.

UTF-8 sequences are validated according to the standard: - 0x00..0x7F - 0xC2..0xDF + 1 continuation byte - 0xE0..0xEF + 2 continuation bytes (with overlong and surrogate checks) - 0xF0..0xF4 + 3 continuation bytes (limited to <= U+10FFFF)

Syntax

Streams.Reader.UTF16Char

Decodes a UTF-16 encoded character from a byte stream into a 32-bit Unicode code point. Returns TRUE if a valid UTF-16 sequence is decoded and ucs is set, FALSE for invalid sequences or insufficient bytes. Handles BMP (U+0000–U+D7FF, U+E000–U+FFFF) and supplementary plane (U+10000–U+10FFFF) via surrogate pairs. Supports big-endian and little-endian byte order.

On success, advances the stream position by the appropriate number of bytes.

Syntax

PROCEDURE UTF16Char* (VAR ucs: Char32): BOOLEAN

Streams.Reader.UTF32Char

Decodes a UTF-32 encoded character from a byte stream into a 32-bit Unicode code point. Returns TRUE if a valid UTF-32 sequence is decoded and ucs is set, FALSE for invalid sequences (U+D800–U+DFFF, >U+10FFFF) or insufficient bytes. Supports big-endian (network byte order) and little-endian byte order.

On success, advances the stream position by the appropriate number of bytes.
