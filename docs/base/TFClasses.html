TFClasses.List.GetCount

return the number of objects in the list. If count is used for indexing elements (e.g. FOR - Loop) in a multi-process situation, the process calling the GetCount method should call Lock before GetCount and Unlock after the last use of an index based on GetCount

Syntax

PROCEDURE GetCount* (): SIZE

TFClasses.List.Add

Add an object to the list. Add may block if number of calls to Lock is bigger than the number of calls to Unlock

Syntax

PROCEDURE Add* (x: @Any0)

TFClasses.List.Replace

atomic replace x by y

Syntax

PROCEDURE Replace* (x, y: @Any0)

TFClasses.List.IndexOf

return the index of an object. In a multi-process situation, the process calling the IndexOf method should call Lock before IndexOf and Unlock after the last use of an index based on IndexOf. If the object is not found, -1 is returned

Syntax

PROCEDURE IndexOf* (x: @Any0): SIZE

TFClasses.List.Remove

Remove an object from the list. Remove may block if number of calls to Lock is bigger than the number of calls to Unlock

Syntax

PROCEDURE Remove* (x: @Any0)

TFClasses.List.Clear

Removes all objects from the list. Clear may block if number of calls to Lock is bigger than the number of calls to Unlock

Syntax

PROCEDURE Clear*

TFClasses.List.GetItem

return an object based on an index. In a multi-process situation, GetItem is only safe in a locked region Lock / Unlock

Syntax

PROCEDURE GetItem* (i: SIZE): @Any0

TFClasses.List.Lock

Lock prevents modifications to the list. All calls to Lock must be followed by a call to Unlock. Lock can be nested

Syntax

PROCEDURE Lock*

TFClasses.List.Unlock

Unlock removes one modification lock. All calls to Unlock must be preceeded by a call to Lock.

Syntax

PROCEDURE Unlock*
