NbrStrings.Int

However, do not mix Nbr and string types. This would yield non-associative addition, e.g., "Number = " + "10" + "20" would yield "Number = 1020" instead of "Number = 30" Instead use "Number = " + Int(10+20) yielding "Number = 30".
